# 📊 Sistema de Notas em C

Programa desenvolvido em linguagem C para calcular a média de um aluno e informar sua situação final.

---

## 📌 Sobre o Projeto

Este programa foi criado com o objetivo de praticar lógica de programação utilizando a linguagem C, especialmente estruturas condicionais e entrada/saída de dados.

---

## 🎯 Funcionalidades

- Receber as notas do aluno
- Calcular a média
- Informar o resultado final:
  - ✅ Aprovado
  - ❌ Reprovado

---

## ⚙️ Tecnologias Utilizadas

- Linguagem C
- Lógica de programação
- Estruturas condicionais (`if`, `else`)
- Entrada e saída de dados (`scanf`, `printf`)
